# تطبيق تلاوة (Tilawa) - المكتبة الصوتية الشاملة والمصحف الشريف

تطبيق أندرويد قرآني حديث ومتكامل مبني باستخدام Jetpack Compose وMaterial 3، مستوحى بالكامل من التصميم المرفق في 19 شاشة متناسقة باللون الزمردي الداكن (Dark Emerald/Teal)، يدمج واجهات برمجية حقيقية لجلب بيانات القراء والسور (Mp3Quran & AlQuran Cloud) مع مشغل صوتي متقدم، ميزة فريدة لمقارنة تلاوات القراء للآية الواحدة، عارض صفحات المصحف الشريف، إدارة التنزيلات، المفضلة، وقوائم التشغيل.

---

## القرارات المؤكدة وخيارات المستخدم

> [!IMPORTANT]
> بناءً على إجاباتك في المرحلة السابقة، تم اعتماد المعايير التالية:
> - **مصدر واجهة البرمجة (API):** شبكة **Mp3Quran** المدعومة بواجهة **AlQuran Cloud** لتوفير قوائم قراء شاملة بأعلى جودة صوتية، وسور مصحوبة ببيانات دقيقة وروابط مباشرة قابلة للتشغيل والتنزيل والتخزين المؤقت.
> - **إدارة الحساب والمزامنة:** الدخول كضيف فوري (Guest Mode) بدون أي عوائق، مع خيار المزامنة السحابية والحفظ المحلي الشامل عبر **Room Database** لضمان عمل التطبيق بكفاءة متناهية دون إنترنت.
> - **المشغل الصوتي وتجربة الاستماع:** مشغل صوتي غني بكامل أدوات التحكم (تسريع، تكرار، مؤقت نوم، تقديم وتأخير) مدمج مع إطار صفحة المصحف الذهبي الأنيق، وميزة حصرية لمقارنة أصوات كبار القراء لنفس الآية.

---

## 1. نظرة عامة والمفهوم الأساسي

- **ما يقدمه التطبيق:** تجربة استماع وقراءة روحانية راقية وسلسة، تتيح للمستخدم الاستماع لمئات القراء المشهورين (عبد الباسط عبد الصمد، مشاري العفاسي، الحصري، المنشاوي، سعد الغامدي، وغيرهم)، وتنزيل السور للاستماع في وضع عدم الاتصال، وإنشاء قوائم تشغيل مخصصة، ومقارنة ترتيل الآيات، وقراءة صفحات المصحف المزين بالزخارف الإسلامية.
- **الجمهور المستهدف:** كل مسلم يبحث عن رفيق قرآني صوتي ومقروء يجمع بين الجمال البصري الفائق وسهولة الوصول والتشغيل دون تعقيد.
- **القيمة الأساسية:** مكتبة صوتية متكاملة + وضع أوفلاين + مقارنة القراء + دعم كامل للغة العربية واتجاه RTL وتصميم فاخر مستوحى من ألوان كسوة الكعبة والزخارف القرآنية الزمردية.

## 2. تجربة المستخدم والتصميم البصري (UX & UI)

### الهوية البصرية ونظام الألوان:
- **اللون الأساسي (Primary):** أخضر زمردي داكن ناعم (`#0B221E` إلى `#0D2E27`) يمنح شعوراً بالسكينة والخشوع.
- **اللون الثانوي والتمييز (Accent / Highlights):** أخضر إسلامي حيوي (`#10B981` / `#059669`) مع لمسات ذهبية شريفة (`#D4AF37` / `#F59E0B`) للأطر القرآنية ونجوم المفضلة.
- **الخلفيات والأسطح (Surfaces):** خلفيات ليلية عميقة (`#081714` و `#0F2621`) مع بطاقات شبه شفافة ذات حدود رقيقة متوهجة وزخارف أقواس إسلامية.
- **الخطوط والطباعة:** خطوط عربية واضحة ومريحة للعين، مع خط مصحفي أصيل لعرض نصوص الآيات والبسملة.

### هيكل الشاشات الـ 19 المتطابقة مع التصميم:
1. **شاشة البداية (Splash):** شعار تلاوة، خلفية الأقواس الإسلامية، زر "ابدأ الآن".
2. **الترحيب والدخول (Welcome / Auth):** خيارات "تسجيل الدخول"، "إنشاء حساب جديد"، وزر "تخطي" الفوري.
3. **الصفحة الرئيسية (Home Dashboard):** شريط البحث السريع، بطاقة "آخر ما استمعته" مع زر استئناف التشغيل، شريط القراء الأكثر استماعاً، وقائمة السور السريعة.
4. **مكتبة القراء (Reciters Directory):** فلترة (الكل، الأكثر استماعاً، الأكثر تسجيلاً، ترتيل)، صور القراء وتفاصيل عدد التلاوات والروايات.
5. **قائمة السور (Surahs List):** 114 سورة بتصنيف مكي/مدني، عدد الآيات، زر المفضلة والتشغيل المباشر.
6. **مشغل التلاوة (Audio Player Screen):** عرض صفحة المصحف داخل إطار ذهبي مزخرف، اسم السورة والشيخ، شريط تقدم الوقت، أزرار التكرار، ومؤقت النوم، وتغيير السرعة.
7. **التنزيلات (Downloads Manager):** تصنيف التنزيلات (جارية، مكتملة، الكل)، مؤشر نسبة التنزيل، والتشغيل دون إنترنت.
8. **المفضلة (Favorites):** السور والقراء المحفوظون لسهولة الوصول بنقرة واحدة.
9. **قوائم التشغيل (Playlists):** إنشاء قوائم مخصصة ("قائمة العائلة"، "تلاوات خاشعة"، "أذكار وسور قصيرة").
10. **البحث المتقدم (Search):** بحث فوري في أسماء السور والقراء والآيات مع استجابة فورية.
11. **الإعدادات (Settings):** المظهر الداكن، جودة الصوت، خيار التنزيل عبر Wi-Fi فقط، وإدارة الذاكرة.
12. **الاستماع دون إنترنت (Offline Hub):** عرض التلاوات المحملة محلياً، ومؤشر استهلاك سعة التخزين.
13. **الملف الشخصي (Profile):** معلومات المستخدم، إحصائيات الاستماع، واختصارات سريعة للمفضلة والإشعارات.
14. **مزامنة الأجهزة (Device Sync):** إدارة مزامنة موضع الاستماع والمفضلة بين الأجهزة.
15. **مقارنة القراء (Reciter Comparison):** اختيار الآية (مثل آية الكرسي)، والاستماع لتلاوات متتابعة بين مشاري العفاسي، عبد الباسط، والحصري مع موجات صوتية تفاعلية.
16. **قراءة المصحف (Mushaf Viewer):** تصفح صفحات السور بنصوص قرآنية واضحة ومضبوطة بالتشكيل داخل إطار ذهبي فاخر مع أزرار التنقل.
17. **مركز الإشعارات (Notifications):** تنبيهات اكتمال التنزيل، وتذكير يومي بقراءة القرآن وسورة الكهف يوم الجمعة.
18. **شاشة انقطاع الاتصال (Offline Banner / Fallback):** تنبيه أنيق عند غياب الشبكة مع زر فوري "الانتقال إلى التلاوات المحملة" و"إعادة المحاولة".
19. **حول التطبيق (About):** رقم الإصدار، سياسة الخصوصية، تواصل معنا، وحقوق النشر.

## 3. المعمارية التقنية واستراتيجية البيانات

```
┌─────────────────────────────────────────────────────────────┐
│                       Jetpack Compose UI                    │
│  [TopBar]  [MainScreens (Home/Reciters/Surahs/Player)]      │
│  [MiniPlayer Bar]  [BottomNavigationBar]                    │
└──────────────────────────────┬──────────────────────────────┘
                               │ StateFlow / Events
┌──────────────────────────────▼──────────────────────────────┐
│                    TilawaViewModel & Audio                  │
│  - Playback State & Progress (MediaPlayer Controller)       │
│  - Active Surah / Reciter / Ayah Comparison State           │
│  - Search Query & Filter Chips State                        │
│  - Offline / Network Status Flow                            │
└──────────────┬──────────────────────────────┬───────────────┘
               │                              │
┌──────────────▼─────────────┐ ┌──────────────▼───────────────┐
│     TilawaRepository       │ │       TilawaDatabase         │
│  - Mp3Quran & AlQuran API  │ │  - FavoritesDao              │
│  - Retrofit HTTP Client    │ │  - DownloadsDao (Room)       │
│  - Offline Cache & Fallback│ │  - PlaylistsDao              │
└────────────────────────────┘ └──────────────────────────────┘
```

### عناصر المعمارية الأساسية:
1. **شبكة الاتصال (Network Layer):**
   - Retrofit + Moshi لجلب بيانات القراء، السور، روابط ملفات mp3 عالية الدقة من شبكة Mp3Quran API و AlQuran Cloud API.
   - كاش بيانات مدمج ذكي (Preloaded Catalog) حتى يعمل التطبيق فوراً بدون أي شاشات بيضاء حتى قبل اكتمال طلب الشبكة.
2. **المشغل الصوتي (Audio Playback Engine):**
   - مشغل صوتي يعتمد على `android.media.MediaPlayer` يدعم البث المباشر (Streaming)، تشغيل الملفات المحملة محلياً، السحب على شريط الوقت، التكرار الفردي/المتتابع، والتوقيف المؤقت واسترجاع موضع الاستماع.
3. **قاعدة البيانات المحلية (Room Database):**
   - جداول `favorites` (المفضلة)، `downloads` (التنزيلات مع المسار المحلي)، و `playlists` (قوائم التشغيل).
4. **أيقونة التطبيق وهوية الحزمة:**
   - تحديث `app_name` إلى "تلاوة" وتحديث `metadata.json` ليطابق الاسم والوصف.

## 4. خطوات التنفيذ المرتبة

1. **تحديث الإعدادات والمكتبات (`libs.versions.toml` و `build.gradle.kts`):**
   - تفعيل `libs.coil.compose` لعرض صور القراء والشعارات.
   - تفعيل `libs.androidx.navigation.compose` إذا لزم للتنقل السلس.
   - ضبط أسماء الموارد في `strings.xml` وتحديث `metadata.json` إلى اسم "تلاوة".
2. **بناء طبقة البيانات والواجهات البرمجية (Data & API Layer):**
   - نماذج البيانات `Reciter`, `Surah`, `Ayah`, `RecitationAudio`.
   - كواشف الاتصال `TilawaApiService` و `TilawaRepository` مع قائمة شاملة لكبار القراء والسور الـ 114 بروابط صوتية حقيقية.
3. **إعداد قاعدة بيانات Room المحلية:**
   - كيانات المفضلة، التنزيلات، وقوائم التشغيل.
4. **تطوير محرك الصوت (TilawaAudioPlayer):**
   - إدارة تشغيل التلاوة، التقديم، التأخير، تكرار الآية، وقائمة الانتظار ومقارنة القراء.
5. **تطوير واجهات المستخدم (Jetpack Compose UI Screens):**
   - تصميم الثيم الإسلامي الماسي والزمردي في `Theme.kt` و `Color.kt`.
   - بناء شريط التنقل السفلي والمشغل المصغر العائم (Mini Player) المستمر في أسفل الشاشة.
   - بناء كافة الشاشات: شاشة البداية، الرئيسية، قائمة القراء، قائمة السور، مشغل التلاوة الكامل مع المصحف، مقارنة القراء، التنزيلات، المفضلة، قوائم التشغيل، والبحث المتقدم.
6. **التحقق والبناء البرمجي (`compile_applet`):**
   - فحص وتأكيد تجميع التطبيق بنجاح بدون أخطاء.
