# تطبيق تلاوة (Tilawa Quran App)

مكتبة صوتية متكاملة للقرآن الكريم ومصحف إلكتروني حديث، مبني بالكامل بأحدث تقنيات أندرويد الحديثة **Kotlin** و **Jetpack Compose** و **Material 3**.

---

## 📱 مميزات التطبيق

1. **مكتبة شاملة لكبار القراء:** تلاوات بأصوات أشهر القراء (عبد الباسط عبد الصمد، مشاري العفاسي، محمود خليل الحصري، محمد صديق المنشاوي، سعد الغامدي، ماهر المعيقلي، ياسر الدوسري، وغيرهم) مع فلاتر وبحث فوري.
2. **سور القرآن الـ 114 كاملة:** مصنفة (مكية / مدنية) مع عدد الآيات وروابط البث المباشر والتنزيل.
3. **مشغل صوتي متقدم:** دعم التكرار للآية أو السورة، تغيير السرعة (1.0x, 1.25x, 1.5x)، تقديم وتأخير 10 ثوانٍ، ومؤقت الاستماع، مع مشغل مصغر عائم (Mini Player).
4. **مقارنة أصوات القراء (Reciter Comparison):** الاستماع لنفس الآية الكريمة بأصوات شيوخ متعددين جنباً إلى جنب مع موجات صوتية تفاعلية.
5. **عرض المصحف الشريف:** صفحات مزخرفة بإطار ذهبي إسلامي ونصوص قرآنية مضبوطة بالتشكيل.
6. **الاستماع دون اتصال (Offline Mode):** تنزيل السور وإدارتها مع عرض المساحة المستخدمة.
7. **المفضلة وقوائم التشغيل:** تخصيص قوائم استماع للعائلة والأذكار والتلاوات الخاشعة.
8. **مزامنة الأجهزة والإعدادات:** الوضع الداكن التلقائي، جودة الصوت، وخيارات المزامنة السحابية.

## 🛠️ البناء والتشغيل عبر GitHub Actions

تم تجهيز المشروع بملفات عمل جاهزة **GitHub Actions CI/CD** في مسار `.github/workflows/`:

- `.github/workflows/build.yml`: يقوم تلقائياً عند أي `push` أو `pull_request` ببناء ملف **APK** ورفعه كملف قابل للتنزيل المباشر (Artifact) من تبويب **Actions** في مستودع GitHub.
- `.github/workflows/release.yml`: يدعم إنشاء حزم **APK** و **AAB (Android App Bundle)** الجاهزة للنشر أو التحميل اليدوي عبر زر `Run workflow`.

### خطوات التحميل بعد الرفع على GitHub:
1. ارفع المشروع إلى مستودعك في **GitHub**.
2. انتقل إلى تبويب **Actions**.
3. ستجد أن عملية البناء `Build & Package APK` قد بدأت تلقائياً.
4. فور اكتمال البناء (علامة صح خضراء ✅)، اضغط على اسم العملية وحمّل ملف `Tilawa-Quran-App-Debug-APK` مباشرة وثبته على هاتفك.

## 💻 البناء المحلي عبر Terminal

```bash
# منح صلاحية التنفيذ للـ Gradle Wrapper
chmod +x gradlew

# فحص واختبار المشروع
./gradlew testDebugUnitTest

# بناء ملف APK لتثبيته على الهاتف
./gradlew assembleDebug

# ملف الـ APK الناتج ستجده في المسار:
# app/build/outputs/apk/debug/app-debug.apk
```
